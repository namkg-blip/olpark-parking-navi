# 올팍 공연일 주차 내비

올림픽공원 공연 날, 언제 도착하고 언제 출발하면 덜 막히는지 공공데이터로 미리 알려주는 웹 서비스입니다.
2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작입니다.

- 서비스: `docs/` (정적 웹, GitHub Pages로 배포)
- 분석·모델: `tools/`

## 사용한 공공데이터

|---|---|---|

| 한국체육산업개발(주)_올림픽공원 2025 차량입출차, 공연, 날씨정보 등 연계 데이터 | 문화공공데이터광장 `API_CPM_009` | 2025 공연일·관람객 수 |

## 모델 요약

- 공연일마다 앞뒤 3주 안의 공연 없는 같은 요일 중앙값을 평소 기준선으로 두고, 17시 이후 초과 출차가 가장 큰 시각을 출차 최고점으로 정의
- 최고점 기준으로 정렬한 초과 출차 곡선의 요일 유형별 중앙값으로 공연일 출차를 예측 (2025년 평일 18회, 주말 17회)
- 출구별 15분 처리량 상위 1%를 처리 능력으로 보고, 공연일 이용 비중과 비교해 여유 출구를 추천
- 교차검증(해당 공연 제외): 러시 지속 시간 60%가 15분 이내 오차, 최고점 출차량 오차 중앙값 83대

## 모델 다시 만들기

문화공공데이터광장에서 서비스키를 받아 저장소 루트의 `.env`에 넣은 뒤 순서대로 실행합니다.

```
KEY_LINKED_2025=...
KEY_PERFORMANCE=...
KEY_INOUT_2025=...
KEY_RENTAL=...
```

```bash
cd tools
python download.py KEY_LINKED_2025 10000
python download.py KEY_INOUT_2025 10000
python build_events.py
python build_inout.py
python analyze_rush.py
python occupancy_check.py
python model_v2.py
```

결과는 `docs/data/model.json`에 저장되고, 페이지는 이 파일만 읽습니다. 서버가 필요 없어 무료 정적 호스팅으로 운영할 수 있습니다.
